How a Binary Search Tree works

Every node keeps values smaller than itself in its left subtree and values larger than itself in its right subtree. That single rule is what makes insert, search and delete all run in roughly O(log n) time on a balanced tree.

Design note: in this visualizer, each node's horizontal position equals its rank in the tree's inorder traversal — so reading the canvas left‑to‑right always shows values in sorted order. Watch how an Inorder traversal simply sweeps left to right!
